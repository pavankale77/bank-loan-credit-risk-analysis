# 🏦 Bank Loan & Credit Risk Analysis

**Tools:** Python, Pandas, NumPy, Matplotlib, Seaborn, SciPy, Statistics

## 📌 Project Overview
This project focuses on analysing bank loan data to understand customer repayment behaviour and identify patterns associated with loan defaults using Python and Exploratory Data Analysis (EDA).

## 🎯 Objectives
- Understand customer and loan information.
- Perform data cleaning and preprocessing.
- Handle missing values and duplicate records.
- Perform feature engineering.
- Conduct Univariate, Bivariate and Multivariate Analysis.
- Analyse distributions and detect outliers.
- Apply statistical techniques and hypothesis testing.
- Generate meaningful business insights.

## 📂 Dataset
- Total Records: 2,512
- Total Features: 14
- Target Variable: `Loan_Status`
- Categories: `Fully Paid`, `Default`

## 🛠️ Technologies Used
- Python
- Pandas & NumPy
- Matplotlib & Seaborn
- SciPy
- Statsmodels
- Scikit-learn
- Jupyter Notebook

## 📊 Analysis Performed
- Data Understanding and Cleaning
- Missing Value and Duplicate Analysis
- Feature Engineering
- Univariate, Bivariate & Multivariate EDA
- Outlier Detection (IQR & Z-Score)
- Distribution Analysis (PDF, CDF, Gaussian)
- Skewness and Kurtosis
- Central Limit Theorem (CLT)
- Confidence Intervals
- Hypothesis Testing
- Correlation Analysis
- Exploratory Risk Segmentation

## 💡 Key Outcomes
- Explored customer loan repayment patterns.
- Analysed relationships between financial variables and loan status.
- Identified potential outliers and data quality issues.
- Practised statistical analysis and business interpretation.

## 🚀 How to Run

1. Clone or download this repository.
2. Install the required libraries:

```bash
pip install pandas numpy matplotlib seaborn scipy statsmodels scikit-learn jupyter
```

3. Open the project folder in VS Code.
4. Open `Bank_Loan_Credit_Risk_Analysis.ipynb`.
5. Run all cells from top to bottom.

**Note:** Keep the CSV dataset in the same folder as the notebook.

## ⚠️ Dataset Disclaimer
This project uses a synthetic/demo dataset created for educational and interview practice purposes. It does not contain real bank or customer records.
